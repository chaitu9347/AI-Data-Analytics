# AI Data Analytics Project

## Project Overview
This project performs exploratory data analysis on an e-commerce dataset using Python and Google Colab. The objective is to identify business trends, customer behavior, regional performance, and product profitability.

## Features
- Data Cleaning
- Monthly Revenue Analysis
- Revenue by Category
- Customer Segment Analysis
- Regional Revenue Analysis
- Top 10 Products by Profit
- Business Insights and Recommendations

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- Microsoft Excel

## Project Structure
- Data Loading
- Data Cleaning
- Exploratory Data Analysis
- Visualizations
- Observations
- Insights
- Hypotheses
- Recommendations

## Installation

```bash
pip install pandas matplotlib openpyxl
```

## How to Run

1. Open Google Colab
2. Upload the notebook
3. Upload the dataset
4. Run all cells

## Results
The project identifies revenue trends, customer patterns, category performance, and profitable products to support business decision-making.
